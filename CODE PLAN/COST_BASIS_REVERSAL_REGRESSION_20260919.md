# IBKR C/O 反向开仓导入回归（2026-09-19）

## 根因与修正

完整 Activity 报表中，同一合约先买入 2 张（O），再卖出 4 张（C;O;P）。第二笔实际先平掉 2 张多仓，再开出 2 张空仓。原解析器只要看到 C 就标记整笔为纯平仓，导致预览告警及数据库拒绝写入。

解析器现在保留 C/O 为 `ibkr_close_open`。股票期权与期货期权的回放、数据库写入及撤销校验都要求：已有非零反向持仓，且本笔成交数量严格大于已有持仓，确实同时包含平仓和开仓。纯 C 的超额平仓拦截保持有效。现金、佣金、成交时间及来源引用保留在一条原始订单记录中，不拆成可重复计费的两条来源。

IBKR 的代码定义参见 [Trades Codes](https://www.ibkrguides.com/reportingreference/reportguide/codestradeconfirm.htm)：C 为平仓，O 为开仓，P 为部分成交。
