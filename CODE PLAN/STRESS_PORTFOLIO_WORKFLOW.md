# 当前组合净值压力测试（已实现）

目标：调整当前账本持仓与选中联动账本保护期权的数量，查看在同一批行情、目标价格和经过天数下的组合净值变化范围。

## 主口径

- 默认使用当前快照变化；旧配置未带 `kernel.workflowVersion: 2` 时迁移到该口径。历史现金流成本仍可在高级设置中明确选择。
- 每次打开默认不计未来收入；原有每周收入数值保留为高级设置中的可选假设，必须明确开启。当前持仓的已收权利金不重新算作未来收益。
- 缺少所选持仓的当前报价时，不把缺失持仓移除后继续显示一个貌似完整的净值结果。历史成本模式的有标签降级功能保留。
- `ΔNAV = Σ 数量 × (情景价值 − 当前价值)`；股票与本账本交割后的股票持有到情景时点，联动期权到期变现后持有现金。
- 可输入与所选组合范围一致的当前净值（含现金）；情景净值为该基数加 ΔNAV。未输入时只展示变化金额，不把账本历史净现金流当作现金余额。

## 数量草稿

- 股票可改股数；每个现有期权合约可改非负整数张数，保留原多空方向，0 表示排除。联动只列出所选账本的多头期权。
- 输入通过 `quantityOverrides` 送入纯估值内核；以账户、合约身份及交割条款生成稳定键，未知键、无效张数直接拒绝。
- 在原报价验证、IV 校准和映射参数确定后调整数量，保持市场假设固定。将保护张数调至 0 不改变本账本 IV 假设或映射。
- 视为从现金支付或释放资金的模拟调仓，显示按当前估值计算的净投入，不凭增仓增加初始净值。未模拟交易费用、滑点或购买力。
- 对照曲线是同一行情、同一时间、同一模型下的账本实际数量；卡片及切片显示当前数量结果与调整的增量效果。对照中线没有另算概率区间。
- 数量改变后不套用原账本历史每股成本，隐藏成本线；恢复实际数量后恢复成本参考。净值计算不依赖历史成本。
- 数量只保存在页面内存；主账本事件变化清除主账本草稿及净值基数，联动账本变化清除联动草稿。刷新页面恢复实际数量。任何模拟均不写账本、不下单。

## 不确定性与交割

- 保留默认勾选的 Short Put 保守交割覆盖规则，参见 `STRESS_KERNEL_REFACTOR.md`。
- 原 β、期限和价外 Put 折扣采样外，加入可调 IV 水平敏感性（页面默认 ±20%，范围 0–50%）。20% 是相对幅度，例如 30% IV 对应 24%–36%，不是 20 个 IV 点，也不是历史覆盖率校准值。
- 对完整组合加入 IV 水平高低情景及与下跌参数组合的边界样本；不将单腿极值相加。0 天、原价格时所有样本仍锚定当前估值。
- 所有上下界均是有限假设采样范围，不是置信区间；不覆盖全部可能路径或完整 Skew 曲面，也不是组合最坏结果保证。

## 验证

测试涵盖：大小变化的线性现金流算例、当前时刻零变化、原报价与账本不变、Short Put 交割与数量一致、零保护不改变市场模型、无效/过期数量键拒绝、IV 水平样本、旧配置迁移、净值基数换算、草稿失效及原数量对照。
