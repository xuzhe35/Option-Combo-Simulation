识别服务与启动说明

RapidOCR 与 Apple Vision 在本机离线运行，图片不会上传云端：Apple Vision 需要 macOS 与命令行工具；RapidOCR 可在 Windows / macOS / Linux 使用，需先在运行服务的 Python 中执行 pip install rapidocr onnxruntime，它的每个数值格都需两次放大读数一致才采用。本机 Codex 使用已安装 CLI 和现有 ChatGPT 登录，把图片发送至 OpenAI 云端模型，直接理解表格与组合关系；不依赖 OCR 表头校准。AI 结果仍须人工核验，没有精确行定位。取消只停止页面等待，已发出的模型请求可能继续，服务不会自动重试。启动独立预览服务后即可识别：

python3 scripts/portfolio_snapshot_ocr_server.py
