识别服务与启动说明

两种引擎都在本机离线运行，图片不会上传云端：Apple Vision 需要 macOS 与命令行工具；RapidOCR 可在 Windows / macOS / Linux 使用，需先在运行服务的 Python 中执行 pip install rapidocr onnxruntime，它的每个数值格都需两次放大读数一致才采用。启动独立预览服务后即可识别：

python3 scripts/portfolio_snapshot_ocr_server.py

在本机浏览器打开 截图 Portfolio。需要 macOS 命令行工具；服务不可用时仍可手填持仓和导入 JSON。
